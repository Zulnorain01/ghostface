Your Gemini API key

GhostFace Studio has no servers and no key of its own — you bring a free key from Google AI Studio. It's stored only in this browser (localStorage), never sent anywhere except Google's API.

  1. Open aistudio.google.com/app/apikey (free Google account)
  2. Click Create API key, copy it
  3. Paste it below and save

Free image quota varies by Google project/region — check yours in AI Studio. Your photo + prompt go to Google's Gemini API to render the portrait.
